# Классификация тональности текстовых комментариев

## 1. Описание проекта
Интернет-магазин с активным сообществом пользователей нуждается в автоматизации модерации контента. Внедрение NLP-инструмента позволит выявлять токсичные реплики в режиме реального времени, снизить объем рутинной ручной работы модераторов и защитить репутацию площадки от агрессии и оскорблений.

## 2. Цели и задачи проекта
Разработать и обучить NLP-модель машинного обучения для бинарной классификации пользовательских комментариев на позитивные/нейтральные и токсичные.

## 3. Исследуемый набор данных
- *toxic_comments.csv* — размеченный корпус англоязычных комментариев (159 292 записи).
- *toxic* — целевой бинарный признак (1 — токсичный, 0 — нейтральный).
- В данных присутствует выраженный дисбаланс классов: 89.8% позитивных/нейтральных комментариев против 10.2% токсичных.

## 4. Ключевые результаты и инсайты
- На тестовой выборке достигнуто целевое значение метрики F1-score = 0.8007.
- Алгоритм успешно детектирует более 80% токсичных комментариев при уровне ложных срабатываний всего в 2.5%.
- Реализован сквозной пайплайн (Pipeline) обработки текста, включающий лемматизацию и TF-IDF векторизацию (с учетом униграмм и биграмм). Проблема дисбаланса классов решена за счет взвешивания классов внутри логистической регрессии.

## 5. Стек технологий
- **Data Manipulation:** pandas, numpy
- **NLP:** spaCy, NLTK
- **Machine Learning:** scikit-learn (Logistic Regression, TF-IDF)
- **Visualization:** matplotlib, seaborn, wordcloud

## 6. Зоны роста
Текущая модель построена на классическом подходе (TF-IDF + Логистическая регрессия). Для дальнейшего повышения качества классификации, улавливания сарказма и более глубокого понимания семантики текста планируется переход к продвинутым нейросетевым архитектурам, в частности — внедрение и дообучение предобученных моделей на базе BERT.
