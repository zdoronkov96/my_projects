# Портфолио проектов Data Science

Добро пожаловать в мой репозиторий проектов по анализу данных, машинному обучения и визуализации! 
Этот репозиторий демонстрирует ключевые навыки, стек технологий и мой подход к решению аналитических задач.

## Проекты

1. [Определение возраста покупателей по фотографии](https://github.com/zdoronkov96/my_projects/blob/main/predicting-the-age-of-buyers)
    - **Описание:** Модель прогнозирует возраста покупателей по фотографии лица.
    - **Стек и технологии:** Computer Vision, ResNet.
    - **Результат:** Средняя абсолютная ошибка модели (MAE) около 7 лет.
2. [Классификация тональности текстовых комментариев](https://github.com/zdoronkov96/my_projects/blob/main/nlp-text-classifcation)
    - **Описание:** Модель выявляет токсичные комментарии пользователей.
    - **Стек и технологии:** NLP,  Logistic Regression.
    - **Результат:** Модель выявляет более 80 % токсичных комментариев при 2.5 % ложных срабатываний.
3. [Прогнозирование следующей покупки](https://github.com/zdoronkov96/my_projects/tree/main/predicting-the-next-purchase)
    - **Описание:** Модель определяет пользователей, готовых совершить покупку в ближайшее время. 
    - **Стек и технологии:** LightGBM.
    - **Результат:** Модель выявляет более 80 % токсичных комментариев при 2.5 % ложных срабатываний.
