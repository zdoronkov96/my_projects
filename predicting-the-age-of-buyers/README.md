# Определение приблизительного возраста покупателей по фотографии

## 1. Цели и задачи проекта
Основная цель исследования — разработать и обучить модель компьютерного зрения, которая по фотографии человека с высокой точностью определяет его приблизительный возраст. 

Внедрение подобного решения в сетевом супермаркете позволяет решать две ключевые прикладные бизнес-задачи:
* **Анализ покупательского поведения:** сегментация клиентского потока по возрастным группам для адаптации выкладки товаров и формирования персонализированных рекомендаций.
* **Контроль кассовой зоны:** помощь кассирам в соблюдении законодательства при реализации товаров с возрастными ограничениями (алкогольной и табачной продукции).

---

## 2. Исследуемый набор данных
В работе используется набор данных с фотографиями лиц людей из открытого датасета **ChaLearn Looking at People**:
* **Размер выборки:** 7 591 разметка в CSV-файле (`labels.csv`) и соответствующая директория с изображениями (`/final_files`).
* **Структура признаков:**
  * `file_name` — имя файла фотографии;
  * `real_age` — целевой непрерывный признак (реальный возраст человека в годах).
* **Статистика целевой переменной:** возраст людей варьируется от 1 года до 100 лет, при среднем значении около 31 года и медиане 29 лет.

---

## 3. Основные этапы исследования
1. **Исследовательский анализ данных (EDA):**
   * Анализ общей структуры и целостности датафрейма (проверка на отсутствие пропусков).
   * Расчет описательных статистик и построение гистограммы распределения возрастов.
   * Визуализация случайной выборки изображений с выводом реального возраста для оценки разнообразия условий съемки (повороты головы, освещение, мимика, качество снимков).
2. **Подготовка данных к обучению:**
   * Настройка генераторов изображений (`ImageDataGenerator`) для пакетирования и нормализации.
   * Применение базовых техник аугментации (например, горизонтальное отражение) для повышения обобщающей способности.
3. **Моделирование:**
   * Использование предобученной сверточной нейросети с архитектурой **ResNet50** (на весах ImageNet) в качестве базовой части (backbone).
   * Замена классификационной «головы» на слой глобального усреднения пулинга (`GlobalAveragePooling2D`) и полносвязный выходной слой с одним нейроном для задачи регрессии.
   * Оптимизация с использованием алгоритма Adam и оценка качества с помощью метрики MAE (Mean Absolute Error).

## 4. Используемые библиотеки и технологии
* **Python 3** — базовый язык разработки.
* **pandas**, **numpy** — обработка табличных данных и числовые вычисления.
* **matplotlib**, **seaborn** — визуализация распределений и вывод графических данных.
* **Pillow (PIL)** — манипуляции и предобработка изображений.
* **TensorFlow / Keras** — построение пайплайна загрузки данных, инициализация ResNet50 и обучение модели компьютерного зрения.
