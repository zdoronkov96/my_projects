# Определение возраста покупателей по фотографии

## 1. Описание проекта
Сетевому супермаркету требуется автоматизировать анализ покупательского поведения и повысить контроль кассовой зоны. Внедрение CV-модели позволит сегментировать клиентский поток для адаптации выкладки товаров, а также будет служить умным ассистентом для кассиров при реализации продукции с возрастными ограничениями (алкоголь, табак).

## 2. Цели и задачи проекта
Разработать и обучить нейросетевую модель компьютерного зрения (Computer Vision) для решения задачи регрессии — предсказания приблизительного возраста человека по фотографии лица.

## 3. Исследуемый набор данных
- Открытый датасет ChaLearn Looking at People.
- Объем выборки: 7 591 размеченная фотография.
- Целевой признак `real_age` — реальный возраст в годах (непрерывная переменная).
- Возраст людей в выборке варьируется от 1 года до 100 лет (среднее значение — 31 год, медиана — 29 лет).

## 4. Ключевые результаты и инсайты
- На отложенной тестовой выборке достигнута средняя абсолютная ошибка MAE = 7.30 лет.
- Погрешность в ~7 лет является критичной вблизи порога совершеннолетия (18 лет). Поэтому модель не заменяет проверку документов, а служит *вспомогательным триггером*. Рекомендуемый сценарий: интеграция с кассовым ПО для автоматического вывода предупреждения «Проверьте паспорт», если нейросеть оценивает возраст покупателя ниже 25–30 лет.

## 5. Стек технологий
- **Data Manipulation:** pandas, numpy
- **Deep Learning & CV:** TensorFlow, Keras, Pillow (PIL), ResNet50
- **Visualization:** matplotlib, seaborn

## 6. Зоны роста
Для снижения MAE и повышения точности в наиболее критичном возрастном сегменте (15–25 лет) планируется применить подход с одновременным обучением регрессии и классификации (многозадачное обучение), добавив классы возрастных групп для лучшей фокусировки градиентов.
